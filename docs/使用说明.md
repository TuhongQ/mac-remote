## 1. 需要准备什么

| 设备 | 要求 |
|---|---|
| Mac | macOS 13 或更新（看屏幕功能用 ScreenCaptureKit，建议 macOS 14+）；装好 Xcode 命令行工具（`xcode-select --install`） |
| iPhone / iPad | iOS / iPadOS 16.4 或更新的 Safari（视频模式要用 WebCodecs）；更老的系统也能用触控板和图片模式 |
| 网络 | Mac 和手机连**同一个局域网**（同一个 Wi-Fi，或者 Mac 插网线、手机连同一路由器的 Wi-Fi） |
| 可选：Apple TV 遥控器 | 同级目录有 [atv-core](https://github.com/TuhongQ/atv-core) 源码，并装好 Rust（`cargo`） |
| 可选：Apple Pencil | 支持「随手写」的 iPad + Pencil（用于手写输入） |

> 建议在路由器里给 Mac 设一个**固定 IP**（DHCP 静态分配）。IP 变了，手机主屏幕上的图标、手表快捷指令里的地址都得重新弄。

## 2. 在 Mac 上安装

```bash
git clone https://github.com/TuhongQ/mac-remote.git
cd mac-remote
./build-app.sh
```

脚本会做这些事（大约半分钟）：

1. 编译 `WatchBridge.swift`，打包成菜单栏 App「**Mac 遥控**」（`build/Mac 遥控.app`）
2. 如果同级目录有 `../atv-core` 并且装了 `cargo`：顺带编译 iPhone「Apple TV 遥控器」的接收端，放进 App 里；没有就跳过这个功能
3. 用一张**本机签名证书**签名（第一次运行时自动生成，放在 `~/.config/watchbridge/signing/`）
4. 停掉旧版的后台服务（如果以前用过 `install.sh`）
5. 安装到 `/Applications/Mac 遥控.app` 并启动

其他用法：

```bash
./build-app.sh --no-install          # 只打包到 build/，不安装、不启动
ATV_CORE=/path/to/atv-core ./build-app.sh   # atv-core 不在同级目录时指定位置
ADHOC_SIGN=1 ./build-app.sh          # 不用本机证书，改用临时签名（每次都要重新授权，一般不用）
```

**为什么要本机签名证书：** macOS 的「辅助功能」授权认的是 App 的签名。每次都用同一把私钥签名，重新编译安装后授权仍然有效；如果用临时签名，每改一次代码都要去系统设置里重新打开开关。这把私钥放在单独的钥匙串文件里，不加入系统钥匙串列表，也不改任何信任设置。

**改了代码或网页之后**：重新运行 `./build-app.sh` 就行。网页（`web/remote.html`）是打包在 App 里的，所以改网页也要重新打包。已经打开的手机网页会在重连时**自动刷新**成新版，不用手动刷新。

## 3. 授权（辅助功能、屏幕录制）

### 辅助功能（必须）

Mac 遥控要模拟鼠标、键盘，必须有「辅助功能」权限。

1. 第一次启动时会自动弹出系统设置的「辅助功能」页面，并且已经把「Mac 遥控」加进了列表
2. 打开「Mac 遥控」的开关
3. App 会在一两秒内**自动重启**并生效（菜单栏里显示「✅ 辅助功能已授权」）

如果没弹出来：点菜单栏图标 →「⚠️ 还没授权辅助功能，点这里去授权…」。

### 屏幕录制（看屏幕才需要）

第一次在手机上打开「看屏幕」时，Mac 会请求屏幕录制权限：

1. 系统设置 → 隐私与安全性 → **屏幕与系统录音** → 打开「Mac 遥控」
2. 按系统提示**退出并重新打开** App（菜单栏图标 → 退出 Mac 遥控，再从「应用程序」打开）

没授权时菜单里会显示「屏幕录制未授权（手机看屏幕要用），点这里去授权…」。

## 5. 用 iPhone / iPad 连接

### 第一次连接

1. 手机和 Mac 连同一个 Wi-Fi
2. 点菜单栏图标 →「**用 iPhone 扫码打开网页遥控器…**」
3. 用手机相机扫二维码，用 **Safari** 打开
4. 页面顶部显示「已连接 192.168.x.x · 9ms」就成功了（后面的数字是网络延迟）

也可以手动输入：`http://<Mac 的 IP>:8765/remote?token=<token>`。token 在 `~/.config/watchbridge/token`，或者菜单里「复制网页遥控链接」。

### 添加到主屏幕（推荐）

Safari 里点「分享 → 添加到主屏幕」。以后从主屏幕图标打开，就是没有地址栏的全屏 App。token 会记在网页里，之后不用再带。

> 如果要用视频模式（第 9 节），请在装好证书、页面自动切到 `https://…:8766` 之后，**再从 https 页面添加到主屏幕**。
>
> 主屏幕网页的状态栏样式等设置只在**第一次打开 App 时**读取。更新后如果顶部被状态栏挡住、或者底部有一条黑边：在多任务界面把它**彻底划掉再打开**；还不行就删掉图标，从 Safari 重新添加。

### 断线与重连

- 手机锁屏、切到别的 App 时连接会断，回来后自动重连
- 断开时 Mac 会自动松开正在按住的鼠标键、结束滚动
- 网页在后台不会反复重连；30 秒没有任何消息的连接会被 Mac 主动断开（比如设备睡着了）

## 6. 触控板手势

不看屏幕时，遥控页中间那一大块就是触控板（像笔记本的触控板）：

| 手势 | 效果 |
|---|---|
| 单指滑动 | 移动鼠标（带加速：慢移精确，快甩走得远） |
| 单指轻点 / 连点两下 / 连点三下 | 左键单击 / 双击 / 三击（选中整段） |
| 双指轻点 | 右键 |
| 双指滑动 | 滚动，松手后有惯性；Safari 里左右滑可前进后退 |
| 双指捏合 / 张开 | 缩小 / 放大（发送 ⌘- / ⌘=） |
| 三指拖动 | 按住左键拖动（拖窗口、选文字、拖文件） |
| 三指轻点 | 中键 |
| 四指左右滑 | 切换桌面（Ctrl+← / →） |
| 四指上滑 / 下滑 | 调度中心 / 应用窗口 |
| 按住「左键」按钮 + 另一只手单指滑 | 另一种拖动方式 |

判断规则（手感参考）：

- **轻点**：每根手指离自己落点不超过 10 点（iPad 14 点），单指 0.32 秒内、多指 0.45 秒内抬起。按「离起点最远的距离」算，手指微微抖动不会把轻点变成移动
- **双指滚动 / 捏合**：看两根手指往哪走——同一个方向是滚动，反方向（指间距明显变化）是捏合；判断之前走过的距离也会补上，所以开头不会「没反应」
- **手指没同时落下**也没关系：先落一根、很快再落第二根，会自动升级成双指手势

界面下方的按钮：**左键**（按住 = 按住鼠标左键，配合另一只手滑动 = 拖动）、**右键**；底部工具栏：**键盘**、**语音**、**快捷**。右上角两个图标：**显示器**（看屏幕）和**设置**。

## 7. 键盘、语音、快捷键

### 键盘面板

点底部「键盘」，有三种模式：

| 模式 | 用法 |
|---|---|
| 实时输入 | 手机上打一个字，Mac 上出一个字。中文用手机自己的拼音 / 手写输入法，选完候选词才发送；⌫、⏎ 直接作用在 Mac 上 |
| 整段发送 | 先在框里写好再发送，适合长句。**语音输入用这个模式**：点手机键盘右下角的 🎤 听写，说完点「发送」或「发送+回车」 |
| 语音指令 | 说「打开微信」「音量调大」「下一首」「截图」等（见第 15 节），点发送后在 Mac 上执行 |

面板下方的按键：esc、⇥、⌫（按住连发）、⏎、方向键（按住连发）、⌘A/C/V/Z、空格、切输入法（Ctrl+空格）、聚焦（⌘空格）、收起。

文字是直接以 Unicode 打到 Mac 上的，不经过 Mac 的输入法，中文、emoji 都可以。个别 App（某些远程桌面、游戏）收不到时，在设置里打开「用剪贴板粘贴文字」。

### 语音

点底部「语音」：HTTPS 页面且浏览器支持时用网页语音识别（中文）；否则打开键盘面板，提示你用键盘上的 🎤 听写（中文效果很好）。

### 快捷面板

点底部「快捷」：调度中心、应用窗口、◀ 桌面 / 桌面 ▶、切换应用、显示桌面、全屏、关窗口、新标签、刷新、后退、前进、放大、缩小、截图、退出 App、上一首 / 播放暂停 / 下一首、静音、音量 ± 、亮度 ±。

## 8. 在手机 / iPad 上看 Mac 屏幕

点遥控页右上角的「显示器」图标，触控区就显示 Mac 的实时画面。再点一次（或画面上的 ✕）关闭。

- **自动横屏**（iPhone）：打开屏幕后界面自动转成横屏布局，左边大画面，右边一列按钮。手机锁定了竖屏也没关系，把手机向左横过来看就行；手机真的转成横屏时也是同样的布局。打字时自动转回竖屏，收起键盘再转回来。可在设置里关掉「看屏幕时自动横屏」
- **点哪点哪**（触控板模式下）：单指轻点画面上的某个位置，会点到 Mac 上的同一个位置；在画面外轻点仍是普通左键。可在设置里关掉
- **帧率**：设置里「屏幕帧率」10–60 帧，默认 30。画面不变时不发新帧，不耗流量
- **左上角小字**：当前帧率和模式，例如「58 帧/秒 · 视频」「画面静止 · 图片」。如果是图片模式，括号里会写原因（比如没用 HTTPS）
- **网络慢时**：手机每收到一帧才回执，Mac 按回执控制节奏，Wi-Fi 跟不上时帧率会自动降下来，但不会越来越延迟

两种画面传输方式：

| | 视频模式（推荐） | 图片模式 |
|---|---|---|
| 怎么传 | Mac 硬件编码 H.264，手机硬件解码 | 每帧压一张 JPEG |
| 流量（同样画面实测） | 不到 1 Mbps | 约 34 Mbps（60 帧时） |
| 清晰度 | 最高 2880 像素宽，画面静止后自动补清晰 | 最高 1800 像素宽 |
| 需要 | HTTPS（一次性装证书，见第 9 节） | 什么都不用 |

## 9. 视频模式与 HTTPS 证书（一次性设置）

浏览器只允许 HTTPS 页面使用视频解码（WebCodecs），所以要让手机信任 Mac 自己生成的证书。每台手机 / iPad 做一次：

1. 手机 Safari 打开 `http://<Mac 的 IP>:8765/ca.cer`，提示下载描述文件时点「允许」
2. 打开「设置」，最上面会出现「已下载描述文件」→ 点进去 → 安装
3. **设置 → 通用 → 关于本机 → 证书信任设置**，打开「**Mac 遥控 本机证书**」的开关（这一步最容易漏）
4. 回到遥控页刷新：页面会自动检测到证书可用，跳转到 `https://<Mac 的 IP>:8766/remote`
5. 在这个 https 页面上重新「添加到主屏幕」，以后都从它打开

确认是否成功：设置面板里「视频模式」下面显示「已开启：H.264 硬件解码」，看屏幕时左上角显示「· 视频」。

没装证书时会自动用图片模式，设置里「视频模式」下面有一步步的提示和证书下载链接。

**自动降级**：如果某台设备解码失败，会自动降低分辨率重试（2880 → 2560 → 1920 → 1600 → 1280 → 960），降到能用的那一档会记住；都不行才退回图片模式（重新打开网页会再试）。把「视频模式」关掉再打开，会从最高一档重新试。

**老版 Safari（iOS / iPadOS 16.x）**：它有个问题，把解码出的视频帧画到画布上会一直画同一帧。网页会自动识别，改用 WebGL 自己画（把 YUV 像素拷出来用着色器转成 RGB），你不用做任何设置。

## 10. iPad 全屏：Mac 适配 iPad 屏幕

iPad 上看屏幕时默认是**全屏**的：

- 画面铺满整个屏幕（在 iPad 状态栏下面，不会被时间、电量挡住）
- 所有按钮收进**右下角的半透明小圆点**。点小圆点，右侧弹出半透明按钮栏：
  - 触摸屏 / 触控板（切换操作方式，见第 11 节）
  - 左键（按住 = 按住鼠标左键）、右键
  - 键盘、语音、快捷
  - ✍️ 手写板（见第 12 节）
  - 设置、✕ 关闭屏幕
- 按钮栏 4 秒不碰、或者手指去摸画面时自动收起；按住左键拖动时、面板打开时不收

### Mac 适配 iPad 的屏幕比例

Mac 屏幕比 iPad 宽（约 1.54 : 1 对 1.33 : 1），按原样显示一定会有黑边。所以 iPad 全屏看屏幕时，**Mac 会临时改用 iPad 的屏幕比例和分辨率**——和 AirPlay 镜像时选「为 Apple TV 优化」一个道理：

- iPad 上画面正好铺满、不留黑边、一像素对一像素（比如 12.9 寸 iPad 开「更多空间」显示模式时，Mac 变成 1590×1168 点，3180×2336 像素）
- 这段时间 **Mac 自己的屏幕左右会有黑边**，窗口也会按新尺寸重新排列（恢复后被挪动过的窗口不会自动回原位）
- iPad 转屏时自动跟着改比例
- **恢复**：关掉 iPad 上的屏幕、切到别的 App、断开连接，2 秒后 Mac 恢复原样；App 退出也会自动恢复。菜单栏里有「**立即恢复 Mac 屏幕**」
- 多台设备都要求适配时，最后打开的那台说了算；它关掉后交给还在看的另一台
- 不想要：设置里关掉「全屏时 Mac 改用本机屏幕比例」

> 这个功能用的是 macOS 的未公开接口 CGVirtualDisplay（BetterDisplay、DeskPad 等软件也在用）：建一个和 iPad 一样大的虚拟显示器（2 倍高清），让 Mac 屏幕镜像它。配置只对 App 本身生效，App 退出时系统自动撤销。

不想全屏：设置里关掉「看屏幕时全屏（按钮收进小圆点）」，就是普通的横屏布局（左边画面、右边一列按钮）。iPhone 默认不全屏，也可以打开。

## 11. 看屏幕时的两种操作方式：触摸屏 / 触控板

看屏幕时，用按钮栏最上面的按钮（或设置里「看屏幕时的操作方式」）切换。iPad 默认**触摸屏**，iPhone 默认**触控板**。不看屏幕时永远是触控板。

### 触摸屏（像用 iPad 一样直接操作画面）

| 手势 | 效果 |
|---|---|
| 点一下 | 点手指下面的东西 |
| 连点两下 | 双击（第二下会自动对齐到第一下的位置，16 点以内、0.4 秒内） |
| 单指滑动 | 滚动手指下面的内容，内容跟着手指走，松手有惯性 |
| 长按（约 0.45 秒）后松手 | 右键（弹出右键菜单） |
| 长按后拖动 | 从按住的位置按下鼠标拖过去（拖文件、选文字、拖窗口） |
| 双指滑动 | 滚动（中途加一根手指也会接着滚） |
| 双指轻点 | 在手指的位置右键 |
| 双指捏合 / 张开 | 缩小 / 放大 |
| 三指拖动 | 从手指的位置按住拖 |
| 三指轻点 | 中键 |
| 四指左右滑 | 切换桌面 |
| 四指上滑 / 下滑 | 调度中心 / 应用窗口 |

**程序坞**：

- 点程序坞图标时，Mac 用辅助功能直接「按」你点的那个图标；长按 = 弹出它的右键菜单。不靠光标去点，因为程序坞有放大、自动隐藏的动画，光标一过去图标就在动，容易点到旁边那个
- 程序坞设成**自动隐藏**时：点画面**最下边一窄条**（约 14 点），只是把程序坞叫出来，不会点下去；出来以后再点图标

### 触控板

和不看屏幕时一样，手指推着光标走（第 6 节）。另外「点哪点哪」开着时，单指轻点画面会点到对应位置。

### 和 iPad 系统手势冲突

iPad 自带的多指系统手势（四五指切换 App、回主屏幕，三指撤销 / 拷贝）会和这里的三指、四指手势抢。想用这里的手势，到 iPad「设置 → 主屏幕与多任务处理 → 手势」关掉系统的多指手势。

### 高刷新率（可选）

Safari 网页默认最多 60Hz。想要 120Hz 跟手：iPad「设置 → App → Safari → 高级 → 功能标志」关掉「Prefer Page Rendering Updates near 60fps」。Mac 屏幕本身是 60Hz，所以画面最多 60 帧，高刷主要让手指、笔更跟手。

## 12. Apple Pencil：直接点、拖、画，点输入框手写

### 直接操作

- 笔尖落下 = 按下左键，移动 = 拖动，抬笔 = 松开。可以直接点按钮、拖东西、在画图软件里画画
- 用笔的时候手掌碰到屏幕会被忽略
- 开着屏幕时，笔点到画面上的对应位置；**没开屏幕时**，整块触控区对应整个 Mac 屏幕（像数位板）
- 用过一次 Pencil 后，手指在触控板模式下的轻点就只是普通左键，「点哪点哪」交给笔
- 笔点程序坞图标也会直接打开那个图标

### 点输入框弹出手写板

用 Pencil **轻点** Mac 上的输入框（搜索框、聊天框、文档……），iPad 会弹出一块几乎全屏的半透明**手写板**：

1. 用 iPad 自带的「随手写」直接在手写板上写，识别出来的文字**实时**打到 Mac 的输入框里
2. 写错了：用笔**划掉**就会删除，自动更正也会同步到 Mac
3. 手写板上方的按钮：⌫（删一个字）、空格、⏎（回车）、完成
4. **手指点一下手写板就关掉**；笔只用来写字

什么时候会弹：Mac 用辅助功能检查，**笔尖下面的那个东西是输入框**、并且**输入焦点也在输入框里**，两个都满足才弹。点按钮、链接、菜单项、勾选框、程序坞图标都不会弹（就算按钮长在输入框里，比如搜索框的 ✕ 也不弹）。

- 哪个 App 的输入框点了不弹：用按钮栏里的 ✍️ 手动打开手写板，并到 Mac 日志里看那一下「点到了什么、焦点在哪」（见第 17 节）
- 不想要：设置里关掉「Pencil 点到输入框时弹出手写板」
- 随手写的语言跟随 iPad 的键盘设置（「设置 → 通用 → 键盘」里加了中文键盘就能写中文）

## 14. Apple Watch

### 14.1 快捷指令「Mac 鼠标」（推荐，不用装 App）

一个菜单式快捷指令，在手表上点按钮控制 Mac：

```bash
python3 shortcuts/make-shortcut.py     # 可以在后面加 Mac 的 IP，不加就自动取
open "build/Mac 鼠标.shortcut"
```

在弹出的窗口里点「添加快捷指令」，它会通过 iCloud 同步到 iPhone 和手表（已设为「在 Apple Watch 上显示」）。

手表上打开「Mac 鼠标」，菜单第一项是 **🎤 语音输入**（固定用普通话识别，说完停顿一下自动结束），之后是左键、双击、右键、上 / 下滚动、光标上下左右移动（每次 150 像素）、语音指令、回车、播放 / 暂停。每点一下执行完会回到菜单，点「退出」结束。

> 生成的文件里带着 token 和 Mac 的 IP（在不进 git 的 `build/` 目录里），**不要发给别人**。Mac 的 IP 变了就重新生成、重新添加一次。

### 14.2 自己做听写快捷指令

在 iPhone「快捷指令」App 里新建，打开「在 Apple Watch 上显示」：

**「Mac 输入」（说什么就打什么）**

1. 听写文本（语言选「中文（普通话）」，停止聆听选「暂停后」）
2. 获取 URL 内容
   - URL：`http://<Mac 的 IP>:8765/type`
   - 方法：`POST`
   - 头部：`Authorization` = `Bearer <token>`
   - 请求体：`JSON`，添加文本字段 `text` = 上一步的「听写文本」
3. 显示结果（可选）

**「Mac 控制」（语音指令）**：同上，URL 改成 `http://<Mac 的 IP>:8765/command`。

可以把它们加到表盘复杂功能上，或者说「嘿 Siri，Mac 控制」。

### 14.3 watchOS App「Mac 遥控」（实验功能，需要开发者模式）

抬起手臂、转动手腕移动光标（体感鼠标），捏一下 = 左键，捏两下（系统「互点两下」手势，Series 9 / Ultra 2 及更新）= 右键，数码表冠滚动。

安装：

```bash
./watch/install-watch.sh
```

前提（一次性）：

1. Xcode → 设置（⌘,）→ Accounts → + → 登录 Apple ID（免费账号就行）
2. iPhone 用数据线连 Mac 并点「信任」；iPhone 和手表都打开「设置 → 隐私与安全性 → **开发者模式**」（会重启）；手表解锁、放在 iPhone 旁边

手表上提示「不受信任的开发者」：iPhone 设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → 信任。免费 Apple ID 签的 App 7 天后过期，重新运行一次脚本即可。Mac 的 IP 变了也是重新运行一次，或者在手表 App「设置 → 连接」里改。

| 动作 | 效果 |
|---|---|
| 左右转手腕 / 上下抬手 | 移动光标 |
| 手臂垂下 | 光标停住（相当于把鼠标提起来），抬起来继续 |
| 拇指和食指捏一下 | 左键（实验功能，靠 App 自己从手腕的细微冲击里识别） |
| 捏两下（系统「互点两下」） | 右键（设置里可改成左键） |
| 转动数码表冠 | 滚动 |

「捏一下」为什么是实验功能：watchOS 只把「互点两下」开放给第三方 App，单次捏合没有系统接口。第一次用请到手表 App 的「设置 → 捏合」里校准：手腕不动捏一下手指，看「刚才的冲击」是多少，把阈值调到比它略低；误触多就调高，或者关掉「捏一下 = 左键」。

> 如果手表一直不显示「开发者模式」选项、Xcode 找不到手表，就用 14.1 的快捷指令。

### 14.4 手表的限制

- 手表要能连到 Mac：手表和 Mac 连同一个 Wi-Fi，或者手表在 iPhone 旁边由 iPhone 中转。离开家用蜂窝网络时连不上
- 手表的听写需要联网手表 App 的说明见 [开发说明](开发说明.md#11-apple-watch-子项目)。

## 17. 常见问题与排查

**手机打不开遥控页 / 一直「连接中」**
- 手机和 Mac 是否在同一个局域网；Mac 的 IP 有没有变（菜单栏里能看到当前地址）
- 菜单栏是否显示「✅ 网页遥控」；显示端口被占用的话，看看是不是旧版后台服务还在（重新运行 `./build-app.sh` 会自动停掉）
- 公司 / 公共 Wi-Fi 可能开了设备隔离，手机连不上电脑

**提示「token 不对」**：在设置里填对 token（菜单「复制网页遥控链接」里有），或者重新扫码打开。

**能连上但鼠标不动**：辅助功能没授权或失效了。系统设置 → 隐私与安全性 → 辅助功能，把「Mac 遥控」关掉再打开；还不行就删掉这一项，重新打开 App 让它重新添加。

**看屏幕提示需要屏幕录制权限**：见第 3 节，授权后要退出并重新打开 App。

**一直是图片模式**：看左上角括号里的原因。「没用 HTTPS」= 证书没装好或没打开信任开关（第 9 节第 3 步最容易漏）；「浏览器不支持视频解码」= 系统太老。

**视频画面不动 / 卡住**：网页会自动处理（解码器压帧时清空并要关键帧、老版 Safari 改用 WebGL）。还不行就把「视频模式」关掉再打开。

**iPad 顶部被状态栏挡住 / 底部有黑边**：把主屏幕 App 彻底划掉重开；还不行就删掉图标，从 Safari 的 https 页面重新添加到主屏幕。

**Mac 屏幕一直是 iPad 的比例、两边有黑边**：iPad 关掉屏幕或切走后 2 秒会自动恢复；也可以点菜单栏「立即恢复 Mac 屏幕」，或者直接退出 App。

**四指切换桌面没反应**：系统设置 → 键盘 → 键盘快捷键 → 调度中心，确认「向左 / 向右移动一个空间」（Ctrl+← / →）是开着的。另外看看是不是被 iPad 自己的系统手势抢了（第 11 节）。

**点程序坞点不中**：程序坞自动隐藏时先点画面最下边一窄条把它叫出来，再点图标。

**Pencil 点按钮也弹出手写板 / 点输入框不弹**：打开日志，找「Pencil 点击：点到 …，焦点 …」这一行，能看到当时识别的结果。

### 日志

- 网页遥控：`~/Library/Logs/watchbridge.log`（菜单「打开日志」）
- Apple TV 遥控器：`~/Library/Logs/atv-remote.log`

日志里常见的行：

| 日志 | 意思 |
|---|---|
| `遥控已连接：192.168.x.x` / `已断开` | 设备连上 / 断开 |
| `设备：iPad，HTTPS 是，WebCodecs 是，…，窗口 …，安全区 上24 下20` | 设备连上时报告的情况（排查状态栏、黑边用） |
| `屏幕镜像已开始（2880 像素宽，最多 60 帧/秒，视频）` | 开始截屏 |
| `H.264 编码：2880×2072，avc1.640034` | 新建了一个视频编码器（尺寸、编码规格） |
| `视频统计：…收到 151 帧，解出 151 帧，…画法 gl` | 设备开屏后第 3、8 秒报告的解码情况 |
| `视频解码出错：…` | 设备解码失败的原因（会自动降级重试） |
| `适配请求：1590×1144 点` / `Mac 屏幕已适配：…` / `Mac 屏幕已恢复原样` | iPad 适配的过程 |
| `Pencil 点击：点到 AXTextArea，焦点 AXTextArea，弹出手写板` | Pencil 点输入框的判断结果 |
| `程序坞：打开「Google Chrome」` | 点程序坞图标 |
| `遥控 x.x.x.x 30 秒没有动静，断开` | 设备睡着 / 断网后被清理 |

## 18. 安全与隐私

- **token**：第一次启动时随机生成，保存在 `~/.config/watchbridge/token`。删掉这个文件再重启 App 会生成新的（之后所有设备都要用新链接）。也可以用环境变量 `WATCHBRIDGE_TOKEN` 指定
- 服务监听所有网卡，**只在可信的局域网里用**。拿到 token 的人能完全控制你的 Mac，链接、二维码、快捷指令文件都不要发给别人
- **本机根证书**：私钥只在这台 Mac 的 `~/.config/watchbridge/tls/`（权限 700）。手机信任它之后，只有持有这把私钥的程序能冒充 https 网站，不要把这个目录拷给别人。不用了可以在手机「设置 → 通用 → VPN 与设备管理」删掉描述文件
- **签名证书**：`~/.config/watchbridge/signing/`，只用来给 App 签名
- 端口：默认 8765（http）和 8766（https）。可以用环境变量 `WATCHBRIDGE_PORT` 或启动参数 `--port` 修改，https 端口总是它加 1
- 屏幕画面只在你打开「看屏幕」时才截取，只发给连着的设备，不保存
